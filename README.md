# Tennis Research

Поиск устойчивых порогов коэффициента k2 (ставка на второго игрока) по историческим
теннисным матчам ATP, с walk-forward валидацией без утечки данных (time leak).

## Источник данных

Исходный файл `CRITERIA_DATA.xlsx` содержит 26 листов по турнирам/покрытиям.
Из расчёта исключены сводные листы **US_hard** и **WE_hard** — они полностью
дублируются более детальными сезонными срезами:

- `US_hard` = `US_hard_feb` + `US_hard_summer` (точное совпадение по ключу
  Date+PL1+PL2, без пересечений и остатка)
- `WE_hard` = `WE_hard_feb` + `WE_hard_oct` (аналогично)

Итого в расчёте используется **24 листа**.

## Метод расчёта порога

1. Матчи внутри временного окна сортируются по возрастанию коэффициента k2.
2. Считается кумулятивная сумма `win2` (профит от ставки на второго игрока)
   по уникальным значениям k2 — агрегация по k2 нужна, чтобы избежать
   зависимости от порядка строк с одинаковым коэффициентом.
3. Порогом выбирается значение k2 с максимальной кумулятивной суммой при
   условии, что число матчей под порогом **не менее 300**.

### Формула win2 / win1

На листах без готовой колонки `win2` она восстанавливается по формуле,
проверенной на листах, где колонка присутствует изначально (расхождение = 0):

```
если win == 0 (выиграл второй игрок): win2 = +100          (флэт-ставка)
если win == 1 (выиграл первый игрок): win2 = -100 / (k2 - 1)
```

Симметрично для `win1`.

### Временные окна

Пороги считаются по 6 окнам: до 2020 вкл., до 2021 вкл., 2016–2022 вкл.,
2017–2023 вкл., 2018–2024 вкл., 2019–2025 вкл.

### Защита от утечки данных (no leak)

Порог для оценки конкретного года Y **всегда** берётся из окна, которое
заканчивается годом Y−1, и никогда — из окна, включающего сам год Y.
Например, для year=2024 используется порог, посчитанный на окне «2017–2023 вкл»,
а не на окне «2018–2024 вкл».

## Группы турниров

**Грунт (2 группы):**
- `SAm_Eu_Clay` — SAm_clay, Eu_Clay
- `Masters_RG` — Madrid, Monte-Carlo, Rome, RG_Q, RG

**Хард + трава (3 группы):**
- `ATP_hard_Masters` — WE_hard_feb, WE_hard_oct, US_hard_feb, US_hard_summer,
  Aus, Chn, US1000_march, US1000_aug, Chn_masters, Paris
- `GrandSlam_hard_grass` — AO, AO_Q, US_open, US_Q, Wimbledon, Wim_Q
- `ATP_grass` — grass

Классификация проверена по фактическим названиям турниров внутри листов
(например, `Paris` — это хардовый Paris Masters/Bercy, а не грунтовый Roland Garros).

## Результаты (`data/processed/`)

Каждый Excel-файл содержит 2 вкладки:

- **Thresholds** — пороги по всем группам и всем 6 окнам (включая 2019–2025).
- **Results_by_tourn_sheet** — построчно по каждому отдельному листу турнира
  и году (2021–2025): `prev.seasons` (сумма win2 за 3 предыдущих года),
  `curr.season` (сумма win2 за сам год), применённый `threshold` (без утечки).

Подробная методология — в `data/processed/config.yaml`.
